# WEB-005 saved-place default and ordering — 2026-10-11

Status: `DONE` in the local `feat/weather-dashboard-upgrade` worktree. Preferences are device-local; no deployment or database change was made.

## Behavior

- Signed-in users can set or clear a default saved place and move saved places up or down.
- Order/default preferences are stored in `localStorage` under a key scoped to the authenticated user ID; only saved-place IDs are stored.
- On a later visit to the dashboard root, the default saved place is loaded through the existing weather endpoint. A URL containing explicit city coordinates always takes precedence.
- Stale preference IDs are ignored; signing out or switching users does not expose another account's local preferences.
