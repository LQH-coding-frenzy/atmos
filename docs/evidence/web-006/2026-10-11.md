# WEB-006 offline dashboard recovery — 2026-10-11

Status: `DONE` in the local `feat/weather-dashboard-upgrade` worktree. The feature is browser-only; no deployment, paid service, or server-side data change was performed.

## Behavior

- The App Router serves a standalone web manifest using the existing SVG app icon.
- Production registers a same-origin service worker. It caches only the queryless app shell and same-origin static assets/MapLibre worker files; it bypasses API/Auth paths, non-GET requests, cross-origin requests, and query-specific location pages.
- The client stores one schema-validated city dashboard locally for offline restore. Device-geolocation snapshots are excluded; API/Auth responses are never cached by the service worker.
- When offline, navigation falls back to the cached root shell and the client restores the last saved city dashboard with `cached`/`stale` metadata and a clear offline banner. Reconnection leaves manual refresh available.
