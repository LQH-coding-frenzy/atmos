## Recommendation and approval boundary

The broadest verified **direct, machine-readable, free official** first integration is the
NWS for its service area plus ECCC for Canada. The UI must identify the source and show
unsupported regions as unsupported, never as “no active warnings.” WMO SWIC is broader as a
public aggregator, but its own caveats and lack of a verified API contract prevent claiming
its participant count as reliable application coverage.

This research task does not make requests from the application. Integration is a separate
owner-approval gate because it adds external warning sources. Before implementing it, retain
the required attribution/User-Agent, avoid modifying alert content/intent, cache and bound
gateway requests, and measure Worker p95 CPU against the 7 ms threshold. Do not add paid
services or credentials as a workaround.
