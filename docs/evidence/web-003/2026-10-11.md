# WEB-003 dashboard UX and Weather Watch — 2026-10-11

Status: `DONE` in the local `feat/weather-dashboard-upgrade` worktree. The changes remain uncommitted; no deployment or production mutation was performed.

## Scope delivered

- City search announces searching, invalid queries, zero results, provider failures, and failed weather selection while keeping the current city visible.
- The current location can be manually refreshed without changing its share URL; failures keep the last weather visible and location requests cancel/ignore superseded responses.
- Temperature units and system/light/dark appearance persist in local storage. Browser storage failure degrades to session-only preferences.
- Saved places can be removed through an authenticated DELETE route, using the existing user-JWT client, explicit owner filter, and existing RLS delete policy. No migration, GRANT, or policy change was made.
- Recorded observations can be downloaded as chronological CSV. Values retain explicit metric units, text is CSV-escaped, and formula-like text is neutralized.
- The dashboard now uses glass surfaces, Material-inspired segmented controls, persistent theme tokens, improved mobile toolbar wrapping, map preview cards, focus rings, and reduced-motion/transparency fallbacks.
- The map loads the OpenFreeMap Liberty style through MapLibre. Visible OpenMapTiles `place` symbol layers are queried for city previews. A focusable visible-city picker provides keyboard access; the selected-city marker remains a fallback when no place-label layers are available.
- MapLibre's worker and shared worker module are copied into same-origin `public/maplibre/` before dev/build; `setWorkerUrl` uses the same-origin worker path, so CSP needs no blob-worker permission.
- City weather previews use a 280 ms hover intent, five-minute in-memory caching, a limit of 12 automatic uncached previews per minute, and abort/stale-response guards. Previewing does not change the dashboard; selecting Open does.

## Provider and security review

- The owner approved OpenFreeMap for the map. Its official site and terms were reviewed on 2026-10-11: public tiles are free, require no registration/API key, allow commercial use, and are provided as-is without an availability SLA.
- MapLibre's style attribution is retained for OpenFreeMap, OpenMapTiles, and OpenStreetMap; the footer also identifies the providers.
- The web Content Security Policy permits image and fetch requests only to `https://tiles.openfreemap.org` in addition to previously allowed sources.
- The saved-place delete API never uses a service-role credential; unknown and non-owned IDs produce the same no-content response under the authenticated owner filter and RLS.
- Map preview requests are limited to named city-point coordinates, not raw pointer coordinates. No new telemetry or durable map state was added.
