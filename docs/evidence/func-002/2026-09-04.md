# FUNC-002 Evidence

## Local Validation

`corepack pnpm exec supabase functions serve api-v1 --no-verify-jwt` loads the profile endpoint in Supabase Edge Runtime 1.74.3.

## Scope

`GET /api/v1/me` requires a caller bearer token, verifies it through Supabase Auth, and queries only RLS-protected profile and preference data with the publishable client. It does not use a secret or service-role key.

## Rollback

Revert the endpoint before remote deployment.
