# FEAT-GEO-001 — Browser geolocation

## Outcome

- Added a visible, keyboard-accessible **My location** action that requests device coordinates only after a user activates it.
- Uses the existing public weather gateway and the browser's resolved timezone; no database, provider, Worker, or infrastructure change was required.
- Handles denied permission, unavailable location, and failed weather lookup with accessible status text.
- Keeps coordinates out of the page URL and browser storage. The selected coordinates are sent to the existing weather gateway only to retrieve weather; no application telemetry or client logging was added.
- Uses a bounded 10-second browser position request, permits a recent cached browser position, and does not request high accuracy.
