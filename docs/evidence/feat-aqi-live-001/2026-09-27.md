# FEAT-AQI-LIVE-001 — Live air-quality experience

## Outcome

- Added a collapsed, on-demand air-quality panel showing U.S. AQI, European AQI, six pollutant concentrations, and model time for the selected location.
- Data comes through the existing Open-Meteo provider and public Worker gateway. The panel does not call the provider until expanded.
- The Worker validates and canonicalizes coordinates, coalesces concurrent misses, caches for five minutes, retains a one-hour stale fallback, and uses the shared Open-Meteo usage guard.
- The UI links Open-Meteo and CAMS ENSEMBLE, shows CC BY 4.0 attribution, labels model estimates rather than ground-station readings, and handles unavailable values without substitutions.
- No paid plan, credentials, new vendor, database, or infrastructure change was made.

## External policy check

- Open-Meteo Air Quality API documentation, pricing, and terms were rechecked on 2026-09-27. The Free/Open-Access API is non-commercial, subject to the existing WX-004 request limits, and the data requires CC BY 4.0 and CAMS ENSEMBLE attribution.
- Open-Meteo documents current air-quality values as 15-minute model data. CAMS resolution is approximately 11 km in Europe and 45 km globally; the dashboard describes these as estimates.
- The on-demand panel and Worker cache/coalescing bound repeated provider requests.
