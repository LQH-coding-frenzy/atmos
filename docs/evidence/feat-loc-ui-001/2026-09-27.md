# FEAT-LOC-UI-001 — Saved locations dashboard UI

## Implementation

- Added an optional email/password account panel backed by the existing Supabase Auth project and browser publishable configuration.
- Authenticated users load and create saved locations through the existing Cloudflare gateway and caller-scoped Supabase API. The dashboard continues to provide public weather without an account.
- Added runtime-validated contracts for saved-location API responses, protected token forwarding, and switching only to locations returned by the API.
- Selecting a saved place keeps its coordinates out of the page URL. No migration, RLS, Worker, provider, or infrastructure changes were made.
