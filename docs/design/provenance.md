# Design Provenance

The user-provided dashboard image and rough Vite design are visual references only. Their bundled avatar and map image are not shipped by the Atmos application.

The production dashboard recreates the visual language with original CSS, Lucide icons, and a MapLibre-ready OpenStreetMap-compatible map surface. The planned map style URL is OpenFreeMap Liberty (`https://tiles.openfreemap.org/styles/liberty`), subject to its current terms and required OpenStreetMap attribution at implementation time.

Do not copy, redistribute, or deploy the reference avatar or map asset without verifying its license.
